7.4 Linux SocketCAN 命令速查

# 1. 加载内核模块
sudo modprobe can
sudo modprobe can_raw
sudo modprobe vcan          # 虚拟 CAN，无硬件也能练习

# 2. 配置并启动接口
sudo ip link set can0 up type can bitrate 500000
# 或带采样点等参数：
sudo ip link set can0 type can bitrate 500000 sample-point 0.875

# 虚拟接口：
sudo ip link add dev vcan0 type vcan
sudo ip link set up vcan0

# 3. 查看接口状态
ip -details link show can0

# 4. 抓包（所有报文，含时间戳）
candump -tz can0          # -t 绝对时间, -z 带方向标记
candump can0,123:7FF      # 过滤 ID 0x123
candump -L can0 > log.asc # 保存为 ASC 格式

# 5. 发一帧
cansend can0 123#1122334455667788
cansend can0 000#0105     # NMT 启动 5 号节点

# 6. 随机流量（压测）
cangen can0 -g 10 -I 185  # 每 10ms 发 ID 0x185
cangen can0               # 全随机

# 7. 回放
canplayer -I log.asc can0=can0

# 8. 查看错误计数器 / 总线状态
ip -s link show can0

7.5 Python canopen 快速示例

import canopen

# 连接到 CAN 总线（python-can 的总线）
network = canopen.Network()
network.connect(channel='can0', bustype='socketcan')

# 添加从站（用 EDS 文件，没有也可以基本通信）
node = network.add_node(5, 'MyServo.eds')   # 或 add_node(5, None)

# SDO 读对象字典
print(node.sdo[0x1018][1].raw)   # Vendor ID
print(node.sdo['Producer Heartbeat Time'].raw)  # 0x1017 名称访问

# SDO 写
node.sdo[0x1017].raw = 500        # 心跳 500ms

# 启动节点
network.send_message(0x000, [0x01, 0x05])   # NMT 启动 5 号

# PDO 映射（示例：配置 TPDO1）
node.tpdo.read()
node.tpdo[1].clear()
node.tpdo[1].add_variable(0x6041)        # 状态字
node.tpdo[1].add_variable(0x6064)        # 实际位置
node.tpdo[1].trans_type = 1              # 每 SYNC 发一次
node.tpdo[1].event_timer = 100           # 100ms 保底
node.tpdo[1].enabled = True
node.tpdo.save()

network.sync.start(0.01)  # 10ms SYNC
node.tpdo[1].wait_for_reception()
print('实际位置:', node.tpdo[1]['Position actual value'].phys)

network.sync.stop()
network.disconnect()

7.7 常见问题调试清单

问题：完全没有报文 / 节点不在线
  1. 万用表测 CAN_H–CAN_L 电阻 ≈ 60 Ω（两端各 120 Ω 并联）。
  2. 确认所有节点波特率一致（看 0x1018、配置工具）。
  3. 用示波器看有无 SOF 边沿，判断是发不出还是被干扰。
  4. 检查 GND 是否共地、供电是否正常。
问题：节点频繁进 Bus-Off
  1. 同上检查终端电阻与拓扑。
  2. 线缆过长或靠近干扰源（电机、变频器），加屏蔽层并单端接地。
  3. 位时序采样点不一致，统一配置（建议 87.5%）。
  4. 用 ip -s link show can0 看 rx/tx 错误计数。
问题：SDO 能通，但 PDO 不发
  1. 确认节点已进入 Operational（NMT 0x01）。Pre-op 状态下 PDO 不传输。
  2. 检查 0x1800 子索引 1 的 COB-ID 最高位是否被置 1（禁用）。
  3. 检查传输类型 0x1800:02：异步需 0x1800:05 事件定时器；同步需有 SYNC。
  4. PDO 映射对象是否 mappable、总长是否 ≤ 8 字节。
问题：CiA 402 伺服不使能
  1. 读 0x6041，看 bit3 Fault 是否置位 → 写 0x6040 = 0x80 复位。
  2. 检查 0x6041 bit4 电压是否正常、bit5 快停是否触发。
  3. 按 0x06 → 0x07 → 0x0F 顺序写控制字，不要跳步。
  4. 看 EMCY（0x080+ID）具体错误码定位硬件故障。
